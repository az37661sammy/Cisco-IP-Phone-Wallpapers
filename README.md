# 🖼️ Cisco IP Phone Wallpapers

A collection of Cisco IP Phone wallpapers, background images, thumbnails, and XML configuration files for various Cisco IP Phone models.

This repository is designed to help users personalize their Cisco IP Phones using FreePBX, Cisco Unified Communications Manager (CUCM), and custom provisioning servers.

## 📄 What is List.xml?

The List.xml configuration file tells compatible Cisco IP Phones which wallpapers are available on the provisioning server.

It contains references to the full-size wallpaper images and their corresponding thumbnail previews. This allows users to browse and select available backgrounds directly from their phone.

Users can also modify the List.xml file to add or remove custom wallpapers.

## ⚙️ Installation Instructions

### FreePBX / Custom TFTP Server

1. Download and extract the wallpaper collection.
2. Locate the folder that matches your Cisco IP Phone model.
3. Open your TFTP provisioning directory.
4. Locate or create the Desktops directory.
5. Upload the corresponding wallpaper folder into the Desktops directory.
6. Ensure that List.xml, wallpaper images, and thumbnail images are included.
7. Restart your Cisco IP Phone if necessary.

## 🖼️ How to Change Your Wallpaper

### Cisco 8800 Series Enterprise

1. Press the Applications button on your Cisco IP Phone.
2. Navigate to Preferences.
3. Select Wallpaper.
4. Browse the available wallpapers.
5. Select your preferred wallpaper.
6. Press Set or Apply.

### Cisco 8961, 9951, and 9971

1. Press the Applications button.
2. Navigate to Preferences.
3. Select Wallpaper.
4. Browse the available background images.
5. Select your preferred wallpaper and save your changes.

### Cisco 7900 Series

For compatible Cisco 7900 Series phones:

1. Press the Settings button.
2. Select User Preferences.
3. Select Background Images.
4. Browse the available backgrounds.
5. Select your preferred background.
6. Press Save.

## ⚠️ Compatibility Notes

- Not all Cisco IP Phones support custom wallpapers.
- Wallpaper resolution must match the requirements of your phone model.
- Enterprise and Multiplatform (MPP) firmware may use different provisioning methods.
- Menu options may vary depending on the phone model and firmware.
- Your system administrator may restrict wallpaper customization.
